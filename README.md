Banking Products Dashboard
A simple banking products dashboard inspired by Standard Chartered Bank's website. 
It allows users to browse banking products, search by name, filter by category and view product details.
----------------------------------------------------------------------------------------
Features
Product Listing: Displays savings accounts, credit cards, loans and investment products.

Category Filters: Filter products based on their category.

Search: Find products by name.

Product Details: View product descriptions and status in a popup.

Responsive Design: Supports desktop and mobile screens.
